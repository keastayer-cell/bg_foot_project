# Этап 7. Продуктовая полировка

Дата завершения: 2026-07-29.

## Цель

Закрыть сквозные пользовательские пути четырёх продуктовых ролей и проверить,
что навигация, route guards и основные рабочие действия образуют цельный
сценарий, а не набор изолированных экранов.

Проверки используют настоящий Vue router, auth store и компоненты приложения.
Backend на уровне браузерных сценариев заменён детерминированным API mock;
серверная ролевая матрица независимо защищена backend-тестами.

## Проверенные пути

| Роль | Вход | Сквозной сценарий | Проверяемый результат |
|---|---|---|---|
| Болельщик | Публичная главная | Активный сезон → таблица → тур → матч → «О лиге» | Публичные данные доступны без авторизации, матч открывается из тура, раздел лиги сразу показывает содержимое |
| Представитель команды | Кнопка профиля в шапке | Кабинет команды → выбор сезона → статус заявки → текущий состав → трансферы | Team scope загружается из access profile, состав и заявка относятся к назначенной команде, трансферный кабинет доступен |
| Рефери | Публичный тур после восстановления сессии | Матч → редактор протокола → сохранение | Видна админ-панель, скрыт API Explorer, протокол сохраняется со статусом `FINISHED` |
| Супер-админ | Админ-панель | Раздел «Роли и доступ» → поиск пользователя → API Explorer | Доступны все административные разделы, профиль пользователя и полный каталог из 97 endpoint'ов |

Каждый сценарий запускается в пяти Playwright-проектах:

- desktop Chromium;
- Android compact, Chromium;
- Android modern, Chromium;
- iPhone compact, WebKit;
- iPhone modern, WebKit.

## Исправления по результатам аудита

### Публичный путь

`LeagueOverview` раньше открывался с `activeSection = null`. Пользователь видел
навигацию страницы, но ни один содержательный раздел. Теперь по умолчанию
открывается «Руководство», а остальные разделы переключаются тем же локальным
меню.

### Устаревший сценарий создания матча

Маршрут `/create` был доступен любому авторизованному пользователю и открывал
старую форму, которая записывала фиктивный матч только в память frontend.
Маршрут не участвовал в актуальном backend workflow туров и протоколов.

Удалены:

- маршрут `/create`;
- `CreateMatch.vue`;
- неиспользуемый `Home.vue`;
- legacy `store/store.js` с демо-сезонами, матчами и локальными мутациями.

Административные матчи теперь создаются только через актуальный раздел туров и
backend API. Route test запрещает возврат client-only редактора.

### Навигация и технические экраны

- публичная и служебная навигация разделены визуально и семантически;
- рабочая ширина главной ограничена без возврата к узкому контейнеру;
- API Explorer и экран теста endpoint получили отдельную техническую ширину;
- экран теста API разделён на endpoint, параметры, сформированный запрос и
  ответ;
- GET без параметров больше не создаёт пустую рабочую колонку;
- layout-тест API Explorer обновлён под новую структуру и проверяет взаимное
  расположение конструктора и preview на desktop/mobile.
