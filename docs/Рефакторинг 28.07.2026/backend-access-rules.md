# Backend access rules

Актуально для `dev` на 2026-07-27.

## Как принимается решение

Доступ проверяется последовательно:

1. `SecurityConfig` задаёт внешний контур: auth/health и все `GET` публичны; изменение данных требует `TEAM_REP`, `REFEREE` или `SUPER_ADMIN`.
2. `ApiAccessRuleFilter` применяет активные правила `work.w_api_access_rule` к непубличным API. Правила кешируются на 30 секунд.
3. `@PreAuthorize` ограничивает административные и судейские endpoint'ы.
4. Сервисы проверяют объектную область: конкретную команду, сезон и разрешение `ROSTER_EDIT`.

`SUPER_ADMIN` имеет полный доступ без поиска правила в таблице. Публичный `GET` одинаково доступен с токеном и без него; закрытые GET дополнительно защищены `@PreAuthorize`.

## Матрица ролей

| Группа endpoint'ов | GUEST/USER | TEAM_REP | REFEREE | SUPER_ADMIN |
|---|---|---|---|---|
| Публичные команды, игроки, сезоны, туры, матчи, таблица, лига | чтение | чтение | чтение | полный |
| `/api/team-rep/**` | нет | только свои team scopes | разрешённые заявки/трансферы | полный |
| Состав `/api/teams/{teamId}/players/{playerId}` | нет | только при `ROSTER_EDIT` | по правилам API | полный |
| `/api/season-applications/**` | нет | отправка своей заявки через team-rep API | просмотр и решения | полный |
| `/api/admin/access/**` | только `me` | только `me` | операции, разрешённые правилами | полный |
| Сезоны, туры, протоколы, судьи | чтение публичной части | чтение | управление | полный |
| `/api/admin/league/**` | нет | нет | управление | полный |

## Source of truth

- Внешний контур: `config/SecurityConfig.java`.
- Динамические правила: Flyway-миграции `V12`, `V13`, `V14`, `V18`, `V24`, `V35`, `V36`, `V38`, `V41`-`V43`, `V47`, `V50`-`V52`.
- Проверки области команды: `AccessControlService`, `TeamRepService`, `TeamRepTransferService`, `PlayerController`.
- Тесты сопоставления method/path/role: `ApiAccessRuleServiceTest`.

При добавлении endpoint нужно одновременно определить внешний контур, добавить миграцию правила для нужных ролей, поставить `@PreAuthorize` для закрытых GET и покрыть правило тестом.
