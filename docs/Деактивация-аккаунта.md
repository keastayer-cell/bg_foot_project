# Деактивация аккаунта

Аккаунт нельзя удалять физически, если с ним связаны подтверждённые протоколы, решения по заявкам, изменения состава или другие действия организатора. Эти записи остаются частью спортивной и административной истории.

## Предлагаемая модель

1. В таблицу пользователей добавляется признак активности и дата деактивации.
2. Деактивация отзывает refresh-сессии и повышает версию access-токенов.
3. Вход для деактивированного аккаунта блокируется, а имя пользователя остаётся в журнале действий.
4. Командные доступы и роли закрываются датой окончания, но не удаляются.
5. Повторная активация выполняется администратором и не восстанавливает просроченные командные доступы автоматически.

Реализацию следует объединить с журналом действий из этапа 11, чтобы деактивация и повторная активация всегда фиксировались с указанием администратора и причины.
