# Каталог событий уведомлений

## Автоматические события колокольчика

| Код события | Условие формирования | Получатели | Публичное | Подтверждение | Email |
|---|---|---|---|---|---|
| `SEASON_STARTED` | Сезон создан или переведён в статус `ACTIVE` | Все зарегистрированные пользователи | Да | Нет | Да |
| `SEASON_CLOSED` | Сезон создан или переведён в статус `CLOSED` | Все зарегистрированные пользователи | Да | Нет | Да |
| `TOUR_PUBLISHED` | Тур впервые опубликован | Все зарегистрированные пользователи | Да | Нет | Нет |
| `TRANSFER_REQUEST_CREATED` | Создана заявка на переход игрока | Представители команды, из которой запрашивают игрока, кроме инициатора | Нет | Да | Да |
| `TRANSFER_REQUEST_APPROVED` | Трансфер подтверждён | Инициатор заявки и представители обеих команд, кроме пользователя, принявшего решение | Нет | Нет | Да |
| `TRANSFER_REQUEST_REJECTED` | Трансфер отклонён | Инициатор заявки и представители обеих команд, кроме пользователя, принявшего решение | Нет | Нет | Да |
| `TRANSFER_REQUEST_REVOKED` | Трансфер отозван | Инициатор заявки и представители обеих команд, кроме пользователя, отозвавшего заявку | Нет | Нет | Да |
| `SEASON_APPLICATION_SUBMITTED_TO_REFEREE` | Представитель отправил состав на проверку | Активные рефери | Нет | Да | Да, отдельным существующим событием mailer |
| `SEASON_APPLICATION_APPROVED` | Рефери одобрил заявку | Представитель команды | Нет | Нет | Да, отдельным существующим событием mailer |
| `SEASON_APPLICATION_RETURNED` | Рефери вернул заявку на доработку | Представитель команды | Нет | Да | Да, отдельным существующим событием mailer |
| `SEASON_APPLICATION_REJECTED` | Рефери отклонил заявку | Представитель команды | Нет | Да | Да, отдельным существующим событием mailer |
| `PLAYER_SUSPENDED_YELLOW` | Подтверждён протокол, после которого игрок достиг порога ЖК и получил дисквалификацию | Активные представители команды игрока | Нет | Да | Да |
| `PLAYER_SUSPENDED_RED` | Подтверждён протокол с КК, повлекшей дисквалификацию игрока | Активные представители команды игрока | Нет | Да | Да |

Публичные события `SEASON_STARTED`, `SEASON_CLOSED` и `TOUR_PUBLISHED` также видны незарегистрированным посетителям. Для гостя прочтение и подтверждение не фиксируются.

## События mailer

### Учётная запись и права

| Код события | Условие формирования | Получатель |
|---|---|---|
| `USER_REGISTERED` | Успешно создана учётная запись | Новый пользователь |
| `PASSWORD_RESET_REQUESTED` | Пользователь или администратор запросил сброс пароля | Владелец найденной учётной записи |
| `TEAM_REP_ROLE_GRANTED` | Пользователю назначены права представителя команды | Назначенный представитель |
| `REFEREE_ROLE_GRANTED` | Пользователю впервые назначена активная роль рефери | Назначенный рефери |

### Сезоны и заявки

| Код события | Условие формирования | Получатель |
|---|---|---|
| `SEASON_STARTED` | Сезон начал действовать | Все зарегистрированные пользователи с email |
| `SEASON_CLOSED` | Сезон завершён | Все зарегистрированные пользователи с email |
| `SEASON_APPLICATION_SUBMITTED_TO_REFEREE` | Команда отправила сезонную заявку | Каждый активный рефери с email |
| `SEASON_APPLICATION_APPROVED` | Заявка одобрена | Представитель команды с email |
| `SEASON_APPLICATION_RETURNED` | Заявка возвращена на доработку | Представитель команды с email |
| `SEASON_APPLICATION_REJECTED` | Заявка отклонена | Представитель команды с email |

Публикация тура (`TOUR_PUBLISHED`) намеренно не создаёт email, чтобы публикация расписания не приводила к избыточной рассылке.

### Трансферы

| Код события | Условие формирования | Получатель |
|---|---|---|
| `TRANSFER_REQUEST_CREATED` | Создан запрос на переход игрока | Представители текущей команды игрока с email, кроме инициатора |
| `TRANSFER_REQUEST_APPROVED` | Переход подтверждён | Инициатор и представители обеих команд с email, кроме принявшего решение |
| `TRANSFER_REQUEST_REJECTED` | Переход отклонён | Инициатор и представители обеих команд с email, кроме принявшего решение |
| `TRANSFER_REQUEST_REVOKED` | Запрос отозван | Инициатор и представители обеих команд с email, кроме отозвавшего запрос |

### Дисквалификации

| Код события | Условие формирования | Получатель |
|---|---|---|
| `PLAYER_SUSPENDED_YELLOW` | При первом подтверждении протокола игрок пересёк установленный для Чемпионата или Кубка порог ЖК | Каждый активный представитель команды игрока с email |
| `PLAYER_SUSPENDED_RED` | При первом подтверждении протокола КК назначила игроку пропуск одного или нескольких матчей | Каждый активный представитель команды игрока с email |

Обычная жёлтая карточка, которая не приводит к дисквалификации, событие не создаёт. Событие содержит внутреннюю ссылку на подтверждённый матч, после которого наступила дисквалификация. Повторная доставка одного типа дисквалификации по тому же игроку и матчу блокируется по источнику уведомления.

## Данные шаблонов

В шаблоны передаются только необходимые данные события. Основные макросы:

- общие: `{{recipientName}}`, `{{recipientEmail}}`, `{{siteUrl}}`, `{{actionUrl}}`;
- сезон: `{{seasonName}}`, `{{seasonId}}`;
- тур: `{{tourName}}`;
- команда: `{{teamName}}`, `{{fromTeamName}}`, `{{toTeamName}}`;
- игрок: `{{playerName}}`;
- решение: `{{decisionComment}}`;
- дисквалификация: `{{tournamentName}}`, `{{suspensionMatchesText}}`, `{{matchId}}`, `{{matchName}}`;
- сброс пароля: `{{resetLink}}`, `{{expiresAt}}`.

Ссылка сброса пароля является одноразовой и ограничена сроком действия. Служебные токены и другие секреты нельзя добавлять в документацию или журналы доставки.
